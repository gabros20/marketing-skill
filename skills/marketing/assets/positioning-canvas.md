# Positioning Canvas

Fill this in order — the order is the method, not a formatting preference. Competitive alternatives
first, because you cannot position in a vacuum; market category last, because the category you claim
depends on everything above it. Source:
[`references/positioning-and-messaging.md`](../references/positioning-and-messaging.md).

This is **craft, not science** — Dunford's five components have no empirical validation and she says
so herself. A filled canvas is a well-argued hypothesis, not a validated finding.

## The five components

| # | Component | Yours |
|---|---|---|
| 1 | **Competitive alternatives** — what the customer would use or do if this didn't exist. Include "nothing" and the manual workaround; a strawman here invalidates everything below | |
| 2 | **Unique attributes** — what this has or does that those alternatives don't | |
| 3 | **Value** — the proven benefit those attributes deliver. Not the attribute restated | |
| 4 | **Best-fit customers** — who cares most about that value, and the buying situation that makes them reach for it | |
| 5 | **Market category** — the frame of reference the buyer already understands. Creating a new category is a high-variance deliberate choice, not a default | |
| 6 | *(optional)* **Relevant market trend** — sharpens timing; never load-bearing | |

## The one-sentence draft

> For **[audience]**, **[product]** is the **[category]** that **[benefit]** because **[reason to
> believe]**.

Working draft, not final copy.

## Messaging ladder — one core claim per audience

| Feature | → Benefit | → Outcome | Proof source |
|---|---|---|---|
| | | | |
| | | | |

A row with no proof source is not finished. Specificity beats superlatives: a named client, an exact
number, a real outcome beats "leading" or "best-in-class" every time.

## Competitive claim check — the defensibility hierarchy

For each competitive claim, mark which tier it actually sits on:

| Claim | Structural (hard to replicate) | Market position (share, recognition) | Feature (copyable, fast) |
|---|---|---|---|
| | | | |

A feature-level claim framed as if it were structural overpromises and ages badly the moment a
competitor ships the same thing.

## Which competitive situation is this?

- [ ] **Displacement** — an entrenched competitor must be actively removed from the account
- [ ] **Attention/budget** — the real contest is for discretionary attention or budget, not a
      head-to-head vendor fight

The GTM motion built on top must match. Treating both as "competitive" the same way is a category
error.

## Before this leaves the room

- [ ] Component 1 names a real alternative, including "do nothing" — not "no one else does this"
- [ ] Every ladder row resolves to an outcome and carries a proof source
- [ ] The claim survives a five-second cold read: a stranger can state who it's for and what it does
- [ ] No jargon only an insider parses
- [ ] Nothing here borrows [`marketing-science.md`](../references/marketing-science.md)'s evidence
      tiers to make this method sound more validated than it is
- [ ] If this is a **re**positioning: a Crawl stage and its go/no-go threshold are written down
      before anything touches primary brand assets
